# Control de Barriles · Demo

Versión de prueba de **Control de Barriles**, una app para llevar el control de una cervecería: fermentadores y tandas, barriles, latas, insumos, recetas, clientes y pagos.

- App de prueba: `index.html`
- Mapa de hacia dónde va la app: `mapa.html`

Los datos que se cargan quedan solo en el navegador de quien la usa. Los datos de ejemplo son inventados.
